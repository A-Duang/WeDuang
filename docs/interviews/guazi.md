## 综合版面经（含瓜子测开）

1. **写单链表交叉的代码**（Y 造型）
   - 找到交叉点后改进，如何很快找到交叉的点
   - 面试官会不停提醒你找到更优解法
   - 结论：先让长链表走差值步，然后同步走
2. **写 SQL 语句**
3. **场景测试题**
4. **设计测试用例**
