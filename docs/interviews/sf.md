4. **协程、线程与进程的区别**
   - 进程：资源分配基本单位，有独立地址空间
   - 线程：CPU调度基本单位，共享进程资源
   - 协程：用户态轻量级线程，由程序控制切换

### Python 基础

5. **Python 面向对象：类函数、静态函数、实例化函数的区别**
   - 实例方法：第一个参数 self，通过实例调用
   - 类方法：@classmethod，第一个参数 cls，通过类或实例调用
   - 静态方法：@staticmethod，无特殊参数，像普通函数
